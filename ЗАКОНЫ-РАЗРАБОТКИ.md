## Факты проекта
Числа завершённого запуска, причина остановки, результат проверки — факты; не
переписываются, исправляются новой записью со ссылкой (Закон 7). Технические проверки и
пользовательское испытание различаются (AGENTS.md). Наличие документа не означает
выполнения кода.

## Снимки и прежние редакции
Снимок решения — один манифест: пути, хеши до и после, размеры. Копии прежних редакций
документов в проект не кладутся и в проекте не читаются; они хранятся вне проекта, оттуда
же берётся откат (Закон 6). Проверка следит, чтобы в каталоге снимка не было ничего, кроме
манифеста.

## Как запускать проверки
```
python3 drafts/rebuild-private/checks/check-docs.py
```
Печатает список проверок и пишет `checks/current-docs-validation.json`. Отчёт содержит
блок `laws`: по каждому Закону — имя проверки либо пометка «ручная».

## Границы
Здесь нет содержания исследования, решений по существу и распределения людей.
Правку текстов документов по существу (ТЗ, карты, глоссарий, журнал решений) выполняет
только владелец — см. ДОЛЖНОСТНАЯ-ИНСТРУКЦИЯ роли Разработчик.
