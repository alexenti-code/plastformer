# PlastFormer-a0 (Gemma4-12B + act grammar + Phi)

## Что это
Первая живая сборка пластформера: Gemma4-12B (4-bit, текстовая) с вшитой акт-грамматикой
v0.1.3 (сборка α: LoRA r=16 на MLP+q,v всех слоёв, k,o не тронуты) + Φ-носитель
(символический банк следов с амплитудами по τ1..τ5).

## Запуск
    cd /Users/alex/plastformer/experiments/o8-pass
    python3 plastformer_run.py

Команды в чате:
- просто говоришь — модель отвечает и (сама) пишет акты памяти;
- `phi` — показать банк следов (id, слой, громкость, содержание);
- `exit` — выход.

Φ сохраняется после каждого хода: experiments/o8-pass/phi_state.json (E4-экспорт).
Сброс памяти: удалить phi_state.json.

## Состав
- Модель: experiments/o8-pass/gemma4-12b-text-4bit/ (текстовая, 4-bit)
- Инструкция (LoRA-адаптер, сборка α): experiments/o8-pass/adapters_alpha/adapters.safetensors
- Носитель: plastformer_run.py (банк, амплитуды, resident prefix, акт-парсер)
- Грамматика: experiments/act-grammar/act-grammar-v0.1-en.md (+ru)

## Ограничения сборки a0
- Φ символический (следы текстом в префиксе), не векторы — целевая форма (банк векторов
  + MAC) — следующий этап;
- surprise/gap-следы выключены (нужен перплексия-датчик, следующий этап);
- fused-вариант (модели/gemma4-12b-plastformer-a0) НЕ ИСПОЛЬЗОВАТЬ: fuse поверх 4-bit
  квантованных весов ломает генерацию — грузить всегда base+adapter через mlx_lm.load.
- Пост-проходная батарея не дала вердикта (память машины не тянет side-by-side);
  переписана на последовательный режим, прогон — следующий шаг.
