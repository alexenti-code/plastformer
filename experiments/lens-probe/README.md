# lens-probe — опыт «объектив» (начало 11.09.2026)

**Что это.** Рабочие артефакты первой части плана сборки (`docs/ASSEMBLY-PLAN.ru.md`, раздел 9): построение якобиева объектива для нашего ядра и замер рабочей полосы. **Не часть изделия** — прибор для настройки.

**Ядро:** `experiments/o8-pass/gemma4-12b-text-4bit` (12B, 48 слоёв, 4 бита).

## Что уже сделано

| Файл | Что в нём | Состояние |
|---|---|---|
| `step1_scan.json` | результаты геометрического скана: CKA между слоями, согласие наивного чтения | **годен** |
| `cka_matrix.npy` | матрица CKA 48×48 (40 подсказок) | **годен** |
| `lens_agree.npy` | согласие наивного чтения слоя с итогом | **годен** |
| `scan_9_1.py` | скрипт геометрического скана | годен |
| `readout_9_2.py` | скрипт наивного чтения слоёв | годен |
| `build_jlens.py` | построение якобиева объектива | **с ошибкой**, переписывается |
| `jlens_Z.npy` | сам объектив | **не годен** (нулевой для слоёв 0–46) |

## Найденное

1. **Полоса есть.** CKA даёт три участка; резкий шов на переходе 10→11 (0,618), дальше гладко.
2. **Наивное чтение промежуточных слоёв даёт мусор** — осмысленные попадания только с 28-го слоя, не выше 35 %. Это совпадает с тем, что пишет статья о своих моделях, и подтверждает необходимость якобиева объектива.
3. **Обратный проход работает:** `mx.grad` даёт градиенты за 0,9 с.

## Ошибка и исправление

Объектив строился подстановкой сохранённых активаций как входов модели. Это разорвало граф: градиент дошёл только до слоя 47. **Исправление:** считать градиент по каждому слою без подстановки, полным прогоном. Цена ≈ 45 с на понятие на слой-цель, около 20–25 минут на 30 понятий.
