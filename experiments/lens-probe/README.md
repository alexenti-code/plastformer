**Что это.** Рабочие артефакты первой части плана сборки (`docs/ASSEMBLY-PLAN.ru.md`, раздел 9): построение якобиева объектива для нашего ядра и замер рабочей полосы. **Не часть изделия** — прибор для настройки.

**Ядро:** `experiments/o8-pass/gemma4-12b-text-4bit` (12B, 48 слоёв, 4 бита).

## Найденное

1. **Полоса есть.** CKA даёт три участка; резкий шов на переходе 10→11 (0,618), дальше гладко.
2. **Наивное чтение промежуточных слоёв даёт мусор** — осмысленные попадания только с 28-го слоя, не выше 35 %. Это совпадает с тем, что пишет статья о своих моделях, и подтверждает необходимость якобиева объектива.
3. **Обратный проход работает:** `mx.grad` даёт градиенты за 0,9 с.

## Ошибки, найденные и исправленные

1. **Первая версия объектива** строилась подстановкой сохранённых активаций как входов модели. Это разорвало граф вычислений: градиент дошёл только до слоя 47, объектив вышел нулевым для слоёв 0–46. **Исправлено:** градиент считается по каждому слою полным прогоном, без подстановки. Цена ≈ 57 с на понятие.
2. **`mx.vjp`** со списком аргументов не принимается в этой версии MLX — рабочий путь через `mx.grad` по каждому слою.

## Что объектив даёт и чего не даёт

**Даёт:** полоса измерима; понятия читаются на средних слоях, где наивное чтение даёт мусор.

**Не даёт (честно):** чтение **шумное**. Корпус — 12 подсказок против тысячи в статье. Выделяются направления, общие для всех векторов понятий, поэтому на любом вопросе всплывают одни и те же слова. Центрирование словаря ослабляет шум, но не убирает. **Чтобы объектив стал прибором, нужен корпус в 50–100 раз больше** — отдельная работа, не блокирующая сборку.
