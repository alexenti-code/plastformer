# gen_material_v05.py — материал v05 для прохода Инструкции

**Статус:** рабочий генератор сборки материала v05 (три слоя).
**Выход:** `experiments/o8-pass/material-v05/` (`train.jsonl`, `valid.jsonl`, `manifest.json`, `REPORT.md`).
**Проверка состава:** внутри того же запуска, результат — в `manifest.json`, раздел `composition_check`.

Генератор не запускает обучение и не трогает веса. Он только собирает текст материала.

## Одна команда (полное воспроизведение v05)

```bash
cd /Users/alex/plastformer
python3 experiments/organ-dataset/gen_material_v05.py
```

С аргументами по умолчанию эта команда даёт ровно ту v05, что лежит в репозитории.
Проверено: повторный запуск даёт побайтово те же `train.jsonl` и `valid.jsonl`.

Явная форма той же команды (записана в `manifest.json`, поле `rebuild_command`):

```bash
python3 experiments/organ-dataset/gen_material_v05.py     --out experiments/o8-pass/material-v05 --seed 42     --bios 38 --exchanges 200 --reflect-per-bio 30     --grammar-share 0.165 --layers 1,2,3     --bio-examples-per-bio 100 --reflect-system hint
```

## Переключатель слоёв

```bash
--layers 1,2,3     все три слоя (по умолчанию)
--layers 1         только грамматика
--layers 2,3       биографии и задачи с вопросом
--layers 1,3       без биографий (быстрая проверка)
```

| Номер | Слой | Что в нём |
|---|---|---|
| 1 | `grammar` | дословные разделы Инструкции и пары «вопрос по грамматике — ответ по Инструкции» |
| 2 | `biography` | биографии пробуждения (конвейер `organ-dataset`) |
| 3 | `reflection` | задачи с вопросом на размышление; правила из контекста убраны |

## Аргументы

| Аргумент | По умолчанию | Смысл |
|---|---|---|
| `--seed` | 42 | сид биографий, отбора грамматики и слоя размышления |
| `--bios` | 38 | число биографий (спецификация: 30-40) |
| `--exchanges` | 200 | ходов в биографии (как в v04) |
| `--reflect-per-bio` | 30 | записей слоя 3 на биографию |
| `--grammar-share` | 0,165 | целевая доля слоя 1 от всего материала (рамка 13-20 %) |
| `--bio-examples-per-bio` | 100 | предел записей слоя 2 на биографию; 0 — без предела |
| `--reflect-system` | `hint` | подсказка слоя 3: `hint` — без перечня актов и правил, но с упоминанием формы блока; `plain` — вообще без упоминания актов |
| `--max-len` | 1280 | предел длины записи в токенах |
| `--window` | 4 | окно истории слоя 2 (как в v04) |
| `--work` | `experiments/o8-pass/.v05-build` | каталог промежуточных файлов; внутрь `material-v05` они не кладутся |
| `--core` | `experiments/o8-pass/gemma4-12b-text-4bit` | ядро; нужен только его токенизатор, для подгонки длины |

## Правки соседних файлов

* `gen_acts.py` — добавлены две вещи, обе выключены по умолчанию, поэтому v04 воспроизводится прежним кодом без изменений:
  * `DIAG_CASES_EXT = []` — необязательное расширение таблицы диагностики для случаев `calibrate`. Заполняется только генератором v05 (`install_diag`), чтобы в материал попадали разные ручки, а не первые четыре строки таблицы;
  * при заполненной `DIAG_CASES_EXT` таблица применяется ко всем целям `probe_recall`, а не к первым двенадцати.
* `gen_biography.py` — **не изменён.** В профиле `production` там опечатка: ключ `"t4"` вместо `"project"`, из-за чего профиль падает. Генератор v05 правит это в памяти после импорта.

## Формат записи

Формат из v04 не изменён: `messages` = system + история + целевой ответ; акты — блоком ```json [...]`; семь актов; слои `t1-t5`; `record_tick` стоит в целевых актах; подтверждения среды — сообщением `<<ENV>>`.

Отличие v05 — системная подсказка по слоям:

| Слой | Системная подсказка |
|---|---|
| 2 биографии | полная, 2137 знаков, с перечнем актов и правилами (как в v04) |
| 1 грамматика | 154 знака, только «ты и твоя память», без актов и правил |
| 3 размышление | 221 знак, то же плюс одна строка о том, что блок актов можно выпустить; **перечня актов и правил нет** |
