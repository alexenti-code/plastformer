**Правила игры (владелец, 07.09.2026):** независимые версии пишутся разными авторами;
сравнение — по качеству исполнения актов после единственного инструктивного прохода (E5-класс метрик:
precision/recall актов, доля валидных актов, покрытие моментов выбора), лучшая берётся
или версии объединяются. Выбор версии — владелец; после выбора грамматика замораживается
вместе с ядром (O-8: один инструктивный проход — вшивание, потом freeze).

**Что должна задавать грамматика (требования):** форму пяти актов (name/repeat/connect/
reconcile/read) и правил применения; ничего семантического (C1/C4 — решения за модель);
ничего из ручек физики (C3); поля записи — по record format (act, content, source, layer,
valid_time, record_tick, refs).
