## Единственный объект работы

Целевая сборка ещё не начата. Единственный объект работы — единый файл **A = (K, Φ)** (см. `docs/ARCHITECTURE-FIXED-BRAIN-v1.md`): секция K (квантованные 4-bit веса ядра с вшитой Инструкцией) + секция Φ (записи Φ1/Φ2, векторы, амплитуды, прожитые тики, происхождение, метки времени, метаданные формата и физики). Вне файла нет состояния экземпляра; любая операция сохранения пишет единый файл A = (K, Φ), а не отдельный банк.

Код нового пути (сборка файла; открытие/изменение секции Φ без изменения K; экспорт/копирование/удаление секции Φ) ещё не написан — его только предстоит спроектировать.

## Ближайшие решения владельца

- пропорция K/Φ;
- точность хранения (4bit/8bit/16bit — влияет на физический размер файла);
- механизм записи в Φ-регион при инференсе.
