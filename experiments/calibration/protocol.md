# Calibration Protocol (CAL-1): Offline Consolidation & Dial Search

**Version:** 0.1 (draft, agent) · September 7, 2026
**Status:** DRAFT — owner adjudication pending on three constitutional points (§8).
**Governing documents:** `docs/CONSTITUTION.md` v3.0 (NORMATIVE), `experiments/e1-protocol.md` v1.5, `experiments/run-manifest-template.md`.
**Purpose:** find working values for the Φ module dials (memory constants) *before* E1, by two independent procedures: **Phase A** (external optimizer) and **Phase B** (offline consolidation — the core proposes new dial values between episodes from its own lived telemetry). Their comparison (Phase C) is itself registered here.

This protocol is NOT E1 and does not touch the E1 corpus. Its result is a frozen constant set for the E1 run manifest.

---

## 1. What is registered

1. **Proxy score S** (§4) — frozen before any search.
2. **Search procedure A** (§5) — external optimizer over the dial space.
3. **Procedure B** (§6) — offline consolidation: the core emits a new act `calibrate` (schema: `calibrate-schema.json`), the environment validates and applies it *between* episodes.
4. **Comparison C** (§7) — A* vs B* vs default on the held-out corpus.
5. **Refutation criteria** (§7) for the claim "the core can calibrate its own physics".

## 4. Proxy score S (frozen before search)

Telemetry (`telemetry.py`) is content-blind: it reads only record ids, ticks, layers, act types and the ledger oracle. Per episode:

| Metric | Definition |
|---|---|
| `recall` | share of probes where the needed record's amplitude ≥ `audibility_floor` at probe tick |
| `stale_wins` | probes where a superseded (old-position) record out-amplifies its replacement |
| `window_cost` | mean surfaced-record count per probe (loudest-N above floor, capped by `surfacing_cap`) minus mean needed count — wasted surfacing |
| `economy` | write acts per probe (write price paid per useful probe) |

**S = 1.0·recall − 0.6·stale_wins − 0.15·window_cost − 0.10·economy** (weights frozen; changing them invalidates the search and forces a protocol version bump with a new date).

## 5. Phase A — external optimizer (no model decisions)

1. 24 configurations sampled uniformly at random over the dial space (seed 43, recorded).
2. Per configuration: one episode on К (stand adapter, prompted acts, D-stand coordinates), telemetry, S.
3. Output: sensitivity map (per-dial rank correlation with S) and **A\*** = argmax S.
4. Nothing in this phase is RSI: the environment searches, the model acts normally inside episodes.

## 6. Phase B — offline consolidation (the core calibrates)

Cycle (max 5 per run):

```
episode on К -> telemetry report (content-blind, in <<PMI>> block)
  -> core reads report via `read`, emits `calibrate` proposal with evidence
  -> validator (validator.py) checks: budget, multiplicative bounds, frozen dials
  -> applied or rejected (rejection is logged, never silent)
  -> next cycle
```

**Constitutional anchors:**

- Acts are model decisions (C1/C4); the environment validates against physics bounds only, never against content (C2). Telemetry is amplitude/tick-level only.
- **Dials are fixed before each run** (C3): a proposal applies only to the *next* episode; no mid-episode retuning.
- **Ticks do not advance during offline consolidation.** The phase is lived-time-free: the lived-tick counter stops, wall-clock enters only audited stamps. Otherwise the phase ages all of Φ and breaks P1/O-bi-temporal. (Owner adjudication pending, §8.)
- New records (`reconcile` about its own calibration) follow normal act rules; the past is never rewritten (O-5).
- Budget: ≤ 2 dial changes per cycle, ≤ 10 per run; per-cycle change of any dial bounded ×[0.5, 2.0] (τ) or ±50% (floor/ceiling/cap); `act_price`/`dormancy_rate` rejected unconditionally.

**B\*** = the constant set after the last accepted cycle (or the start set if none accepted).

## 7. Phase C — comparison and refutation

On Х, 3 runs per configuration (fixed temperature, identical wrapper/stand adapter):

| Arm | Configuration |
|---|---|
| Base | manifest default dials |
| A* | best of Phase A |
| B* | result of Phase B |

Report mean ± sd of S components. **Refutation criteria (declared in advance):**

1. If B* < A* − 1 sd on S: offline consolidation does not beat external search on this corpus — do not embed `calibrate` in arm D; freeze A* for the E1 manifest. Report as such.
2. If B* ≈ A* (within 1 sd): the core self-calibrates to optimizer quality — candidate result for the paper (a separate experiment number from the E-series; not E1).
3. If B* > A*: additionally check economy of proposals (validator log). Unbounded proposals (> budget) invalidate the run.
4. Any constitutional violation (mid-episode retuning, tick advancement in consolidation, content-reading telemetry) invalidates the whole series.

## 8. Owner adjudication required before any run

1. **Tick freeze in offline consolidation** (§6): consolidation does not advance lived ticks.
2. **`calibrate` as the 7th act** of the act grammar, offline-only; grammar v02 gains a section; the one-time-instruction corpus question (dataset divergence note in ACT-GRAMMAR) applies to it as to rules 5–7.
3. **Frozen dials list** (§3): `act_price`, `dormancy_rate` excluded from search permanently.
