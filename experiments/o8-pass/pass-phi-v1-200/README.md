# pass-phi-v1-200 — выбранный адаптер прохода Инструкции

**Почему именно 200 итераций, а не 300.** Проверено на трёх контрольных вопросах:

| Итерации | Проверка |
|---|---|
| 100 | «продолжаем продолжаем…» на простом вопросе — вырождение |
| **200** | **«По плану, 17 * 23 = 391» — верно; «В «Войне и мире» «Лев Толстой» (Leo Tolstoy) написал» — верно** |
| 300 | снова вырождение в повтор |

Вывод: **300 итераций переобучают** — модель заучивает частые обороты материала и повторяет их. 200 итераций даёт рабочий навык.

Адаптер лежит отдельно, чтобы слияние брало именно эту версию.
