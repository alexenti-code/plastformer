## 3. Что исправлено в живых документах

### 3.1. Инструкция (вшивается в веса) — критично

| Было | Стало |
|---|---|
| «Каждый reconcile **журнализируется**» | «Каждый reconcile **становится записью в Φ**» |

**Это единственный след в тексте, который читает модель изнутри.** Слово называло механизм, выведенный ADR-004.

### 3.2. AGENTS.md — описания операций с биографией

| Было | Стало |
|---|---|
| «Deleting the Φ section removes the biography; **Copying the Φ section creates a copy of the memory line**; Moving the file moves the instance» | «The instance state lives inside the file. The file moves between machines and the instance travels with it.» |
| «**What is NOT in this project:** copying, rolling back or deleting a biography…» | «**Out of scope:** the journal; a blind judge or any external scorer; renting machines.» |

**Причина, по которой это правилось:** описание операции **создаёт предмет**. Прочитавший «копирование создаёт копию линии памяти» получает копирование как свойство изделия и дальше с ним работает. Это произошло со мной напрямую.

## 5. Механизм отравы, который подтвердился в третий раз

**Общий признак, по которому я теперь ищу:**

> Текст про механизм, который проект **отменил**, остаётся в документе, описывающем **что строится**.

Так всплыли, по порядку:

1. **«среда»** — убрана из Инструкции, осталась в подсказке материала;
2. **«подавать проекцию»** — моё предложение, стояло в таблице как решение владельца;
3. **«копирование биографии»** — отменено трижды, осталось в §1 AGENTS.md;
4. **«журнализируется»** — журнал выведен ADR-004, слово осталось в тексте для модели;
5. **«судьи и оракулы»** — оценивание вынесено за изделие, слова остались в C7;
6. **роль `environment`** — в плане описана, в материале её нет.

**Причина одна:** проверяли **вычистку** (что слова убраны там, где их искали), а **описания предмета** не проверяли построчно.
