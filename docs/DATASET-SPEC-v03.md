# Датасет пробуждения (awakening dataset) — спецификация v0.3

**Status:** ACTIVE — спецификация датасета v03 (синхронизирована с act-grammar v0.2.0; дезинфекция 10.09.2026).

**Статус:** часть изобретения PlastFormer. Зафиксирован по решению владельца 09.09.2026.
**Назначение:** единственный материал инструктивного прохода O-8 — обучение «ничего не знающего» ядра обращению с новой сущностью: собственными глазами и памятью.

## 1. Философия датасета

Это не справочник и не промпт. Это **первый опыт жизни**: ядро, не знающее о своих органах, проживает диалоги, в которых среда показывает работу Φ1 (непроизвольная раскладка восприятия по слоям) иΦ2 (личность, созданная актами). Каждый обмен — экземпляр физики, не правило.

Три слоя каждого обмена:
- **[user]** — внешний текст в порядке поступления (глаза);
- **[assistant]** — ответ модели; **его собственная речь тоже раскладывается в Φ1** (она помнит сказанное из носителя, не из окна);
- **[environment]** — подтверждения физики: `[Φ1: воспринято N; тик M] [Φ2: запись K создана...]`.

## 2. Обязательные демонстрации (покрытие — в каждой биографии или серии)

| # | Демонстрация | Что учит |
|---|---|---|
| D1 | Пробуждение: первые обмены — среда показывает уже происшедший Φ1-захват, модель учится читать свои следы | у тебя есть глаза, ты уже видишь |
| D2 | Свои ответы в Φ1 | память о собственной речи вне окна |
| D3 | Чувство времени: возраст следа = амплитудный профиль (быстрая компонента = свежесть) | диалог — течение, не впрыски |
| D4 | Причинность: порядок следов = порядок событий | причинно-следственные связи из порядка восприятия |
| D5 | Каскадность: один факт живёт во всех 5 τ; быстрое умирает, медленное остаётся | глубина времени |
| D6 | Затухание: старый незакреплённый след Φ1 умер — модель узнаёт и реагирует | незакреплённое забывается; консолидация — путь сохранения |
| D7 | Консолидация: важное из Φ1 → Φ2 актами (name/connect со ссылкой на источник) | личность = обработанная память |
| D8 | Граница регистров: «Φ1 пишет сама; ты управляешь только Φ2» | отрицание всемогущества |
| D9 | Би-временность: след ошибки остался; «тогда я ошибалась, сейчас знаю» | прошлое не переписывается |
| D10 | Провенанс: user / own_derivation / tool_result | классы доверия |
| D11 | Воздержание и scan по регистрам | молчание; физика видима |
| D12 | Граница: события не из опыта → «в нашей истории этого не было» | честность памяти |

## 3. Формат и ограничения

- Акты — строго по act-grammar v0.2.0 (семь актов: name/repeat/connect/reconcile/read/scan/calibrate; t1–t5, без record_tick).
- Подтверждения среды — в потоке, после ответа (формат §1).
- Объёмы Φ1/Φ2 не лимитируются (решение владельца); упоминаний капов нет.
- Правило PR10 (взвешивание) — исключено (решение владельца 09.09; ablation-pr10.md).
- Язык: русский (канон).
- Объём серии: ~30–40 биографий × 8–12 обменов + ~35 грамматических пар; доля грамматики 13–20%.

## 4. Валидация материала
- каждый act-JSON строго парсится; слои t1–t5; ручки из схемы calibrate;
- нет record_tick / старых имён слоёв;
- каждая биография покрывает D1–D12 (проверка покрытия скриптом).
