# ADR-003: Constitution v2.0 — двухчастный основной закон

**Дата:** 2026-09-05. **Автор:** Архитектор (агент). **Утверждение:** ожидается от владельца.
**Повод:** обзор владельца показал, что CONSTITUTION v1.0 — только «уголовный кодекс» (10 запретительных статей), без основ строя. Принципы доверия были разбросаны по пяти файлам (GLOSSARY акс. 1–9 и Разрешения, MANIFEST, THEORY §1, SPEC) и частично вообще не вошли в v1.0.

## Решение

1. **Двухчастная структура.**
   - **Часть I «Основы строя»** — 11 утвердительных статей (О-1…О-11), собранных из существующих источников. Ничего не изобретено; каждая статья снабжена провенансом. Первая статья — Доверие (О-1).
   - **Часть II «Соблюдение»** — прежние P1–P10, содержание охраны не изменено. Словарь вычищен до ролей (модель / среда / носитель / журнал): убраны «executor», «stand», имена env-переменных и продуктов — закон не зависит от того, как сегодня называются коробки.
2. **Канон** — английский `CONSTITUTION.md`; русский экземпляр `CONSTITUTION.ru.md` для владельца (канон старшинствует при расхождении).
3. **Статус:** DRAFT до явного утверждения владельцем; затем NORMATIVE.

## Разрешённые конфликты линии

| Конфликт (из аудита C1–C10) | Разрешение |
|---|---|
| C6: MANIFEST «cannot be copied» vs акс.8 «копия — ветвь» | Принята акс.8: копия создаёт ветвь (О-3). Норма MANIFEST — superseded |
| C1/C2: «calendar existence», «owner provides time» | Приняты прожитые тики (О-4); нормы — superseded |
| C5: «layers exist» как места | Принято «слои — скорости» (О-2/P3); норма — superseded |
| «executor» как действующее лицо закона | Слово изъято из Части II; роли: модель, среда, носитель, журнал, транспорт |
| PMI как понятие закона | Изъято; разнесённая топология — переходная форма (примечание документации), не сущность закона |

## Дисциплина

- Файлы THEORY/GLOSSARY/MANIFEST не пересматриваются (уже чистые по ADR-002); v1.0 заменяется файлом v2.0; датасет, Mist, протокол не затронуты.
- Содержательные правки протокола/кода по v2.0 — отдельным батчем после утверждения.
