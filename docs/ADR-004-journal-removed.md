# ADR-004: журнал и крипто-стирание исключены из архитектуры

**Дата:** 2026-09-05. **Решение владельца**, дословно: «Я считаю не надо никакого журнала в пластформере. Это каждый может сделать сам. Нашему изобретению/улучшению этого не надо»; про стирание через ключи: «это бред, забудь».

## Решение

1. **Журнал — не часть PlastFormer.** Внешняя полная хроника — стандартная инженерная практика, которую любое развёртывание добавляет само; это не предмет изобретения. Из архитектуры, закона и заявлений проекта журнал исключён: PlastFormer его не включает, не требует и не заявляет. Аудит поведения модели возможен только средствами, добавленными снаружи развёртыванием.
2. **Крипто-стирание (ключи шифрования как механизм права на забвение) исключено** из подхода проекта. Стирание — вопрос владения носителем и его физики, не криптографии.
3. **Следствия для Конституции v2.1:** статья О-8 «Доверие проверяемо» и P8 «Журнал» удалены; статьи перенумерованы (О-1…О-10, P1…P9). В О-9 «Дополнение, не замена» добавлено: внешняя журнализация — вне архитектуры. Слово «журналируемый» в P5 заменено на «зафиксированный записью в Φ» (акт сам создаёт запись — append-only носителя остаётся).
4. **Следствия для линии приоритета:** свойство статьи (tamper-evidence) далее опирается на append-only природу носителя (записи не редактируются; смена позиции — новая запись), а не на внешнюю хронику. Проверка покрытия и хэш-сцепление — вне заявлений проекта (фикс F15 из аудита отменён как неактуальный).
5. **Tamper-evidence — вне проекта (дополнение, тот же день).** Решение владельца: «тихая правка — её возможность или невозможность — тоже не относится к проекту. Мы не занимаемся разработкой безопасности на этом этапе». Проект не разрабатывает и не заявляет механизмы детекции тихой правки. Append-only природа носителя остаётся физикой (записи не редактируются), но заявления о выявлении перезаписи снимаются: README (claim P2), THEORY §P2-note, ADR-001 строка, препринт (7 вхождений: абстракт, P2, §5 D3, §8) — батч v0.6. Конституция v2.1 не упоминает tamper-evidence — правки не требует. Судьба свойства P3 (poisoning cost) — отдельное решение владельца в батче v0.6.
6. **Предстоящая правка препринта (батч v0.6):** §3.8 (журнал) — убрать или перевести в примечание о внешней опции; §6 — переписать без крипто-стирания; tamper-evidence — снять с заявлений (см. п.5).

ADR-003 остаётся в силе, кроме строк таблицы миграции, ведущих к О-8/P8 (аннулированы настоящим решением; нумерация статей смещена).
