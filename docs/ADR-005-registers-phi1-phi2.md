# ADR-005: Регистры памяти Φ1/Φ2 и консолидация

**Статус:** УТВЕРЖДЕНО владельцем 09.09.2026 (обсуждение Φ1/Φ2, решение «запускай»). **Поправка C4 внесена в Конституцию 12.09.2026** — до этого дня действующий текст C4 объявлял незаконной любую запись Φ без акта модели, то есть 87 % памяти. Конституция теперь читается согласованно с этим ADR.
**Мотивация:** конфликт C4 (записи без акта) против surprise-регистра (препринт §3.3, E1 v1.6); формулировка владельца: «личность — это память, которую модель сама себе создала и обработала; память — то, что фиксируется непроизвольно».

## 1. Два регистра одной пластичной части Φ

Φ остаётся единой пластичной частью тела (О-3, co-located). Вводятся два **регистра** по происхождению записи — не места хранения, не контейнеры (О-10 не нарушается; τ-спектр общий):

- **Φ1 — бессознательный регистр (непроизвольная раскладка восприятия).** Решение владельца 09.09.2026 (уточнение): Φ1 — это раскладка по слоям ВСЕГО воспринимаемого СРАЗУ, в момент восприятия: внешние тексты в порядке поступления и СОБСТВЕННЫЕ ответы модели (модель помнит, что говорила — из Φ, не из окна). Даёт чувство времени: след имеет возраст внутри самой сессии (диалог переживается как течение, а не однократные впрыски) и базу причинно-следственных связей (порядок восприятия = порядок событий). Плюс сигнальные записи физики: всплеск неожиданности (перплексия), след-событие разрыва после спячки. Аналогия владельца: открытые глаза — не записать нельзя. Никакого внешнего классификатора (C2, embedding-суррогат запрещён). Объём Φ1 и Φ2 — не лимитируется (решение владельца 09.09.2026); физика затухания остаётся единственным ограничителем живости следа.
- **Φ2 — личность (сознательная память).** Пишется только явными актами модели. Это записи, которые модель сама создала и обработала. Существующая реализация банка — это Φ2.

## 2. Поправка C4 (редакция v3.1)

«Единственные записи в **Φ2** — явные акты модели плюс явный `read`. В **Φ1** пишет только физика: воспринимаемое оставляет след по порогу захвата (перплексия выше замороженного порога), плюс сигнальные записи разрыва (surprise, gap); акта модели для этого не требуется. Перевод содержания Φ1 → Φ2 — только явными актами модели. Молчание — не согласие...» (остальная часть C4 без изменений).

**Поправка к первой редакции этого пункта (12.09.2026).** Здесь стояло «в Φ1 пишется только физикой из внутреннего сигнала ядра (surprise, gap)». Это читалось так, будто в Φ1 попадает **только** сигнал, и противоречило §1 того же ADR, где Φ1 — «раскладка ВСЕГО воспринимаемого сразу: внешние тексты и собственные ответы модели». Противоречие снято: физика — способ записи и её порог, а содержимое Φ1 — воспринимаемое. Так же читается препринт §3.3 (запись по превышению порога предсказательной ошибки) и Теория §5.

C5 не меняется: записи Φ1 не двигают тики (физика письма не проживание).

## 3. Консолидация

Консолидация — работа модели с Φ1 существующими актами: `read` (расширяется на Φ1), затем `name`/`connect` пишут в Φ2 обработанное содержание. **Нового акта не вводится** (один субъект — один набор актов). Необработанные следы Φ1 умирают по физике (короткие τ по умолчанию) — незакреплённое забывается.

## 4. Физика Φ1

- порог захвата: перплексия > threshold (dial, заморожен в манифесте);
- амплитуды: только быстрые компоненты по умолчанию (t1/t2-спектр), громкость невысока;
- объём Φ1 и Φ2: БЕЗ лимита (решение владельца 09.09.2026 — ядро, Φ1, Φ2 могут быть равны; в будущем объединение субстанций оставит неизменным только ядро законов и воспитания); затухание остаётся единственной физикой живости;
- следы Φ1 видны модели в scan; в резидентный префикс попадают только после консолидации (Φ2) — восприятие = личность + сам сигнал разрыва; сырой Φ1 в фон не попадает (не превращать захват в наплыв);
- бюджет захватов на тик — ручка C3.

## 5. Следствия
- Грамматика v0.2.0: без изменений форм; read получает режим Φ1; словарь моментов дополняется ориентиром «своди Φ1 в Φ2».
- E1: surprise в main run теперь легален по канону (ранее конфликт).
- THEORY §5 unconscious register — реализуется как Φ1; препринт §3.3 соответствует.
